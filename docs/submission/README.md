# 最终提交材料索引

本目录按比赛最终提交要求整理材料。建议最终在飞书中建立 3 个文档，并把本文档中的内容复制进去：

- 设计文档：系统架构、技术栈、依赖环境、目录结构、配置说明、关键问题解决方案。
- 说明文档：如何部署、如何体验产品、评委如何快速验证核心链路。
- 项目亮点/创新点：建议控制在 3 条以内，突出和普通 RAG 问答方案的差异。

演示视频不需要提交文档链接，但可以按 `demo-video-script.md` 录制 5-10 分钟讲解视频。

## 提交项对应关系

| 提交项 | 本仓库材料 |
| --- | --- |
| 设计文档 | `design-document.md` |
| 说明文档 | `usage-guide.md` |
| 演示视频 | `demo-video-script.md` |
| 项目亮点/创新点 | `highlights.md` |

## 建议飞书文档结构

如果最终平台要求填写飞书链接，可以这样整理：

```text
飞书文档 1：ShopGuide Agent 设计文档
  -> 复制 docs/submission/design-document.md

飞书文档 2：ShopGuide Agent 说明文档
  -> 复制 docs/submission/usage-guide.md

飞书文档 3：ShopGuide Agent 项目亮点与创新点
  -> 复制 docs/submission/highlights.md

视频附件或网盘链接：
  -> 按 docs/submission/demo-video-script.md 录制
```

注意：飞书文档权限建议设置为“组织内可阅读”或“获得链接的人可阅读”，避免评审打不开。
